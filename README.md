# RMSK Website — Radha Madhav Seva Kunj Trust

यह एक Hindi-first static website starter है।

## शामिल पेज
- `index.html` — मुख्य वेबसाइट
- `gausewa.html` — विस्तृत गौसेवा पेज
- `styles.css` — पूरा responsive design
- `script.js` — mobile menu और year
- `assets/logo.png` — आपका दिया हुआ official RMSK logo

## आपकी photos कहाँ लगानी हैं
इन नामों से अपनी photos `assets/` folder में रखें:
- `hero.jpg` — homepage hero
- `gausewa-hero.jpg` — गौसेवा page hero

इसके बाद gallery/medical/activity sections में placeholders की जगह आपकी photos जोड़ी जा सकती हैं।

## अगला content update
दान/UPI/Bank details को केवल ट्रस्ट के verified details मिलने के बाद जोड़ें।
Registration, PAN, 12A/12AB, 80G, FCRA आदि केवल verified documents के आधार पर प्रकाशित करें।

## Design direction
Website का information architecture Krishnayan के Gausewa page से प्रेरित है — जैसे mission, activities, medical care, support/donation, gallery और contact को एक लंबी कहानी में रखना — लेकिन RMSK के लिए content और branding अलग रखी गई है। Krishnayan का page इन प्रकार के sections को एक साथ प्रस्तुत करता है। 


## Temporary AI photos
The current `assets/*.jpg` files are temporary AI-generated visuals used to complete the design.
Before the website goes live, replace them with RMSK's real photographs using the same filenames where possible.

### Main image sizes
- `hero.jpg`: 1600 × 700 px or wider
- `gausewa-hero.jpg`: 1600 × 700 px or wider
- service/gallery images: 1200 × 800 px recommended
- gallery thumbnails: 1000 × 700 px recommended
- logo: transparent PNG, preferably 800 × 800 px or larger

Keep the important subject near the center of the image because the website crops photos responsively.
